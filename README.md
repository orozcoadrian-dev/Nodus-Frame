## About

**Nodus Frame** is a learning project focused on taking the first steps into **agentic AI development**.

The project explores how AI agents can go beyond simple text generation by combining reasoning, tools, context, memory, and actions to accomplish specific objectives.

This repository was created as part of an introductory workshop on agent-based systems, documenting both the concepts learned and the practical experiments developed throughout the process.

---

## Objectives

- Understand the fundamentals of agentic AI.
- Identify the main components of an AI agent.
- Explore how agents make decisions and execute tasks.
- Experiment with tools and external actions.
- Understand the role of memory and context.
- Build simple agents through practical exercises.
- Document the learning process and results.
